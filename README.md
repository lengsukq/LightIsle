## 为什么选择轻屿？

很多热爱生活的人家里，都有一台常年插着电、性能强劲却多半在待机的 Mac mini；或者，你一直渴望为全家搭建一个私密、安心的照片与影音中心。

也许你曾心动于**飞牛私有云（fnOS）**、**极空间**等现代家庭 NAS 的清新交互，或者考虑过购置一台动辄数千元的**群晖（Synology）**、**威联通（QNAP）**专用硬件，甚至动过折腾**黑群晖**刷机的念头——却常常被高昂的硬件溢价、嗡嗡作响的风扇噪音、复杂的 Linux 运维，以及强行格式化原有硬盘的风险所劝退；又或者，你早已厌倦了公共商业网盘的限速、画质压缩与隐私担忧。

**你的 Mac，本就是一台极其完美的家庭私有中心。**  
它拥有业界顶尖的能效比、强大的媒体芯片算力，以及静谧无声的运行体验。为什么还要为了 NAS 去刷机、去额外添置一台笨重喧闹的设备？

**LightIsle（轻屿）应运而生。**  
我们希望在 Mac 上，也能拥有媲美**飞牛 NAS** 与**群晖**的流畅家庭体验，但**不逼你放弃熟悉的 macOS，更不做另一套封闭沉重的操作系统**。它是一个真正懂得 Mac、更懂家庭温暖的轻量管理助手。无需改变原有使用习惯，双击点开 App，就能让家里的每一位成员轻松拥有属于自己的云上私有空间。

### ✨ 倾心打造的美好体验

#### 🌿 不换系统，不折腾，原位守护
- **告别黑群晖与刷机折腾**：无需购买专用 NAS 硬件，无需刷写 Linux 系统，直接作为 macOS 原生应用运行。你的 Mac mini 依然是心爱的桌面电脑、开发机或影音播放终端。
- **致敬飞牛与群晖的现代体验，但更懂 Mac**：在时光相册、私人影院（海报墙刮削）、文件分享与多成员管理上，带来与飞牛私有云、群晖 DSM 同样出色的家庭级交互体验，同时兼具 Apple 软硬件协同的精致质感。
- **尊重已有文件习惯**：无需将原有外接硬盘格式化，也不强行改变文件目录结构。插上移动硬盘或硬盘柜，原位授权即可立刻开启共享与浏览。

#### 📸 时光家庭相册 · 珍藏每一次欢笑与成长
- **原图无损归仓**：把散落在全家人手机里的珍贵照片收归一处，全分辨率无损备份，告别手机“空间不足”的焦虑。
- **智能时间线与足迹地图**：宝宝的第一声啼哭、全家人的海边度假、四季流转里的生活琐碎，顺着时间与足迹优雅铺展，长辈也能轻松翻阅。

#### 🎬 属于全家人的私人影院 · 点亮每一个惬意周末
- **精美海报墙自动呈现**：智能刮削电影与剧集封面、演员阵容与剧情简介，杂乱的文件名瞬间变成典雅的私人片库。
- **释放 Apple Silicon 强大算力**：充分发挥 M 系列芯片的硬件级视频编解码能力，高码率 4K 影片也能秒开流畅播放，支持按需转码与智能外挂字幕。

#### 🏡 亲密有间，各得其所
- **专属私密空间**：为每位家庭成员创建独立账号，个人相册与私人文档严格隔离，守护每个人的专属小秘密。
- **温馨共享大厅**：家庭旅行合集、公共影音库一键放入共享根目录，一人上传，全家尽享。
- **清晰合理的存储配额**：按物理硬盘为成员设置独立配额，避免单人占用过多容量，给全家稳稳的守护。

#### 🧩 自由生长的应用插件 · 随心打造家庭专属数字岛
- **告别 Docker 内存黑洞与低频常驻税**：在 Mac 上跑传统 Docker 容器，仅虚拟机底噪就要吃掉数 GB 内存；而几天才看一次的小工具若常驻后台，也会白白消耗系统资源。轻屿独创**按需唤醒与纯静态轻量生命周期**——纯静态页面与报表永远 0 MB；动态后端平时休眠（0 MB），家人打开时秒级唤醒，用完闲置自动休眠释放，把每一分内存与算力都留给生活。
- **任何语言，皆可自由构建家庭小应用**：无论是 Python、Node.js、Go、Rust、Java 还是纯 HTML 页面，无需繁琐的容器打包，一段轻巧的代码或脚本即可化作内嵌在轻屿中的私有家庭小程序。
- **统一入口与按成员授权**：告别端口记不住、各配一套密码与穿透的“端口地狱”。所有应用在轻屿中统一单点登录，管理员可按家庭成员精准授权（仅管理员可见、全家可用、指定成员专享），家人在手机 App 或 Web 工作台中像打开内置功能一样顺畅直达。
- **原生拥抱 AI 时代（内置开发者 MCP Server）**：支持现代 AI 协议（Model Context Protocol）。你可以直接让 Cursor、Claude Code 等 AI 编程助手连接 Mac 上的轻屿，一句自然语言指令（例如*“帮我写一个监控家里宽带流量的插件”*），AI 便能自动遵循规范生成脚手架、编写代码并热重载到轻屿应用中心，让灵感随心成真。

#### 🌐 随时随地，随心相伴
- **细腻优雅的多端界面**：无论是电脑浏览器中的 Web / PWA，还是针对手机与平板悉心打磨的移动客户端，处处流淌着 Apple HIG 风格的克制与精致。
- **千兆局域网满速与安全穿透**：在家享受千兆内网飞一般的传输快感；出门在外，亦可通过安全加密隧道（如 Cloudflare Tunnel / FRP）随手翻看家中资料。

#### 🛡️ 数据在手，无可替代的安全感
- **没有窥探，没有审查**：所有数据完整保留在您自己的物理硬盘中，拒绝商业云盘的扫描与限速。
- **贴心的硬盘识别与防误删保障**：精准识别物理磁盘身份；当硬盘离线或松脱时，清晰引导用户检查，绝不在后台胡乱篡改或迁移数据。

## 开启你的轻屿之旅

只需三步，即可让你的 Mac 变身家庭数据中心：

1. **准备运行**：在搭载 Apple Silicon（M1 / M2 / M3 / M4 等）且系统为 macOS 14 Sonoma 或更高版本的 Mac 上打开 LightIsle。
2. **初次初始化**：根据 Mac 原生管理端指引，创建管理员账号，并勾选用于 NAS 存储的原生目录或外接硬盘。
3. **全家连接**：在同一局域网下的浏览器访问初始化地址（默认 `http://127.0.0.1:16666/` 或 Mac App 显示的局域网地址），或使用移动客户端扫描连接，开始享受私有云的便捷与美好。

> [!CAUTION]
> **安全小贴士**：家庭环境默认推荐在受信任的局域网中使用。若需要远程访问，请配置 HTTPS 或搭配安全隧道工具使用，切勿直接将未加密的 HTTP 端口直接暴露在公网环境下。
