# 轻屿 LightIsle

![LightIsle 轻屿 Logo](assets/brand/lightisle-logo.svg)

> 为 Apple Silicon Mac mini 设计的轻量、高效、真正以原生 macOS App 形式运行、可通过浏览器管理的开源个人 NAS。
>
> **2026-10-23 最新个人版定位：** macOS 原生文件系统、系统 SMB、Spotlight/FSEvents、Time Machine 与 SQLite 能力优先；LightIsle 做 Web/Flutter、权限、相册影视和本地管理，不另造企业存储系统。**不自研文件+数据库联合事务恢复、完整跨盘事务引擎或新一套增量备份系统。** 具体范围和安全兜底见 [个人版 fnOS 对标与排期](docs/FNOS_PARITY_PRIORITIES.md)。这仅是产品规划变更，**并非当前功能已经实施或发布门禁已修改**。
>
> **状态：M1–M5 开发预览，未达到正式发布标准。** Mac App 做初始化、系统监控、服务/存储配置和本机备份恢复；文件、图库、影视及账号管理由 Web 与 Flutter 用户客户端实现。仓库内已有 Go 单测/集成测和打包冒烟脚本，但真实磁盘、GUI、规模/72 小时、Android 实机和签名公证验收**尚未完成**。新增 Flutter 用户客户端，优先 Android、macOS、iOS；实现与验收边界见 [Flutter 客户端](docs/FLUTTER_CLIENT.md)。Docker/Colima 管理作为后续可选扩展。

LightIsle（轻屿，暂定产品名）将 **文件管理、图库、影视、存储与系统管理** 整合为面向个人的私有数据空间。保留 macOS，不安装替代操作系统；基础 NAS 服务不依赖 Docker。

**产品形态是一个完整的 `LightIsle.app`，不是一个退出应用后仍独立运行的服务器。** 双击启动 Mac 应用就启动内置 Go 后端；**关闭主窗口仍留在菜单栏提供 NAS 服务**，完全退出应用（⌘Q/菜单栏退出）才结束 Go 后端和 LightIsle 的媒体任务，Android 连接随之断开。可选启用用户登录项与防系统空闲休眠，**不使用独立常驻 launchd NAS 服务或后台守护进程**。这套新生命周期已完成代码编译，仍需真实 GUI/休眠测试。[详见 App 生命周期](docs/MACOS_APP.md)。

## 平台范围（硬性约束）

- **后端：仅 macOS arm64（Apple Silicon）**，面向 Mac mini；不支持、不规划 Linux 后端、macOS x86_64 后端或 Windows 后端。
- **macOS 本机客户端：SwiftUI + AppKit 原生管理端**，负责首次创建管理员、系统监控、后端状态、远程 HTTPS 开关和共享目录授权。**不内嵌文件、图库、影视等用户业务页面。**
- **网页端：Vue 3 / PWA**，覆盖桌面浏览器和 Android 手机浏览器。
- **NAS 宿主安装目标：macOS arm64**。新增 `apps/flutter` 用户客户端，优先 Android、macOS、iOS；它连接已有 NAS，首次初始化、存储授权、备份恢复仍由 Mac 原生管理端负责。现有 Web/PWA 保留。
- 底层平台适配只实现 macOS arm64，不额外抽象跨系统的 Linux Provider。

## 产品特点

- **轻量低占用**：一个 Go 核心后端；媒体扫描、生成缩略图、刮削与转码按需运行；无强制 Redis/PostgreSQL/JVM。
- **内置 NAS 三核心（推进中）**：Web 文件管理、图库及影视直放初版均已开发，本机视频封面与编码探测已接入，不兼容格式按需转码仍待实现。
- **原生 Mac 能力**：通过 Swift/macOS API 使用 FSEvents、ImageIO、AVFoundation 和系统磁盘能力。
- **App 与后端同生命周期**：启动应用自动启动 Go 子进程，退出应用优雅关闭服务；意外退出时 Go 自动检测父进程离开。
- **跨端设计方向**：macOS 原生 App 与 Web/PWA 采用一致的色彩、圆角和层级规范；Flutter 用户端复用相同设计 token，并按 Android、macOS、iOS 的屏幕与输入方式适配。详见 [设计系统](docs/DESIGN_SYSTEM.md)。
- **统一官方 Logo**：初始化动画、Mac 侧栏、Finder/Dock App 图标、Web 登录、浏览器标签和移动端主屏共用同源蓝紫六边形图形。构建自动生成全尺寸素材，见 [品牌资源说明](assets/brand/README.md)。
- **Android 浏览器管理（开发预览）**：管理员在 Mac 应用中手动开启 HTTPS 局域网服务后，通过账号密码登录；自签名证书需要核验指纹。Android Flutter 客户端已提供可选照片后台备份与局域网 NAS 发现，系统调度及真实网络仍需设备验收。
- **安全默认**：初始只监听 127.0.0.1；首次管理员由 Mac App 通过私有 IPC 创建，HTTP 不提供注册管理员入口。其他账号由管理员在 Web 创建；SQLite + Argon2id + 会话授权；共享目录只能 Mac 本机选择。Web 登录会话最长 30 天，停用账号或重置密码会撤销相关会话。
- **本机固定端口与密码恢复**：默认 Web 地址为 `http://127.0.0.1:16666/`；在 **Mac App → 设置 → 本机 Web 端口** 可修改，完全退出并重新打开后生效。忘记首任管理员密码可在 **Mac App → 设置 → 管理员安全 → 重置管理员密码**，使用 macOS Touch ID 或系统登录密码验证设备所有者身份后修改。仅本机私有进程通道可以执行重置；旧管理员会话会失效，Web 没有公开重置接口。可选 Touch ID 钥匙串存储需要先验证已有轻屿密码。

**重置成功仍提示用户名或密码不正确？** Mac「设置 → 管理员安全」现在会直接显示**当前数据库中实际的首任管理员用户名**，重置成功提示也会显示具体修改了哪个账号。请点击同页「打开当前 Web 登录页面」，用显示的用户名和刚设置的新密码登录；不要复用浏览器之前保存的旧密码或以前的随机端口标签页。新密码不会改动用户名，也不会修改其他管理员的密码。排查时不要删除 `accounts.sqlite` 或重新初始化。
- **模块化、但不微服务化**：仅 App 打开时运行单一 Go Core；Docker/Colima 仅作为可选应用扩展。

### 管理端与用户客户端

- **Mac 原生管理端**：启动 Go Core；首次使用时原生设置首任管理员；系统 CPU/内存/磁盘监控通过私有 IPC 采样；配置 HTTPS 远程访问、授权共享目录，提供“打开 Web 用户端”入口。
- **Web 用户端**：首次未初始化时提示用户先到 Mac；初始化完成后只提供账号登录，不开放注册；文件管理、图库、相册、收藏、影视中心与管理员账号管理全在 Web。
- **Flutter 用户客户端**：Android、macOS、iOS 共用文件、图库、影视、账号与任务界面，通过现有 HTTP API 访问 NAS；[运行与验证说明](docs/FLUTTER_CLIENT.md)。退出 Flutter 客户端不会停止 NAS。
- **生命周期**：完全退出 Mac 原生管理端后 Go 和 Web 服务一起退出；Mac App 最小化时继续运行。不提供独立常驻 NAS 守护进程。

### 当前文件管理功能

- 在 Mac 原生 App 的「数据与存储 → 当前 NAS 存储位置」查看完整共享路径与所属磁盘；「可用磁盘与存储位置」会列出已挂载卷、容量和状态。对可写外置盘可直接点击「在此磁盘选择存储目录…」，在该盘内新建或选择 **LightIsle 专用文件夹**。也可通过「选择其他文件夹…」选择用户主目录下的合法子目录。更改前必须确认：**原文件不会自动迁移或删除**，媒体库会重新扫描，切换后需核对旧分享/上传；个人 Beta 只有一个生效的共享根，设置仅允许 Mac 本地管理员操作，Web 不能指定磁盘路径。参见 [存储配置 Beta 计划与验收边界](docs/STORAGE_CONFIGURATION_BETA_PLAN_2026-10-23.md)。
- **外置盘离线与 NTFS 处理**：配置过的磁盘断开时会提示接回原盘，可默认保留记录等待重新连接，或在两次确认后清理旧盘的本地媒体索引、旧权限/下载链接和兼容根登记，并切换至 Mac 私有默认目录；**不会删除原磁盘上的文件**。Mac 端显示 NTFS 只读原因，外置盘「格式化磁盘…」仅打开系统磁盘工具供用户选择 APFS（Mac 专用）或 exFAT（Mac/Windows 通用）并由系统确认抹盘，LightIsle 不运行自动擦盘命令。详细风险与清理范围见 [离线盘及格式化安全计划](docs/OFFLINE_DRIVE_AND_FORMATTING_PLAN_2026-10-23.md)。
- **个人硬盘管理（Mac + Web 管理员复用）**：Go Core 统一外接盘设备、卷格式、容量、SMART 原始状态、挂载/重命名/安全弹出及设备身份校验；Mac「数据与存储」和管理员 Web「设置 → 硬盘基础管理」共用该服务。禁止成员操作、强制卸载、系统盘修改以及 NAS 活跃存储盘危险操作。详见 [硬盘管理 Beta 计划](docs/DRIVE_MANAGEMENT_BETA_PLAN_2026-10-23.md)。
- **Web 文件上传体验**：文件页提供拖拽、多文件选择、校验和传输分阶段进度、取消、成功/失败反馈；修复上传异常被后续目录刷新清空的问题，错误代码转为用户可读提示。详见 [Web 上传修复说明](docs/UPLOAD_UX_BETA_FIX_2026-10-23.md)。
- Web 文件页支持游标分页、创建文件夹、上传断点续传（最高 32 GiB，4 MiB 请求分块）、Range 下载、预览、批量移入回收站；搜索是 30,000 项上限的限量遍历，不是完整全文索引。目录 ZIP 通过 `GET /api/v1/files/archive?path=...` 流式生成，最多 2 GiB / 2,000 项 / 16 层子目录；跳过未授权对象和符号链接，超过上限拒绝导出，不缓冲整个压缩包。
- Web「偏好设置」支持账号本人验证旧密码后修改密码（成功后原子撤销该账号所有会话），并可查看最近 100 条有效登录会话、退出指定会话或只保留当前设备。会话列表不记录或暴露设备位置、IP 或 Cookie 原文，只有登录和创建时间；远程用户不能执行 Mac 本地管理员恢复。
- 管理员可在 Web「已有空间成员」为**已启用的普通成员**设置新密码，操作后该成员的会话全部失效；Web 不开放管理员密码强制重置。文件页可为有权读取的**单个文件**生成 1 小时至 7 天的限时下载链接（最大 2 GiB，单账号最多 100 条），无需访问者登录；设置页可撤销链接。服务端每次重新检查文件身份、账号启用状态与目录授权；链接凭据仅存 SHA-256 摘要，并在备份和离线恢复时剔除，避免旧链接复活。链接仅在创建时展示一次，不支持匿名上传或文件夹分享。
- 删除采用 App 内部回收站，支持按原路径恢复；发生同名冲突时拒绝覆盖。外接卷离线不会转写到其他共享目录，可在 Mac 设置中手动重新连接。
- **同卷操作与跨卷复制是两件事**：同共享卷内的改名/移动使用排他原子重命名；文件/目录复制在私有临时树中逐文件校验后发布。Mac「存储」页可把共享目录中的对象**复制**到另一块磁盘；单文件还可明确选择“复制后移入回收站”，校验目标后保留可恢复源文件，异常时保留两个副本或回收站记录。目录移动和重启续传队列仍未完成。
- Web 图库首版支持按需扫描照片/视频、SQLite 索引、部分 EXIF 拍摄时间、时间线、收藏、相册以及 macOS 按需缩略图；缩略图缓存默认 1 GiB，可在 Mac 设置中调整为 256 MiB–8 GiB 并按最近使用淘汰。Mac App 已增加 FSEvents 变更触发及 Go 周期核对；随包 ImageIO/AVFoundation Worker 读取 HEIC 时间/方向并生成照片与视频封面，Web 支持有界虚拟渲染和相册改名/删除/移出。增量任务检查点和大规模性能验收仍未完成。
- **Web 影视中心 M4 初版**：管理员按需扫描共享目录的视频文件；SQLite 索引电影/剧集，按文件名识别年份/季集；Web 提供筛选、搜索、影片改名、MP4/WebM HTTP Range 原文件播放、同名 VTT/SRT 字幕与每用户独立续播进度。未适配的格式支持下载用本地播放器打开。
- **M4 当前边界**：随包 Worker 从真实容器探测编码、时长和尺寸，按需截取本机视频封面；直放状态区分已探测/待尝试/仅下载。NFO/TMDB 手动资料匹配已接入，自动刮削、MKV/MOV 转码、VideoToolbox/HLS 自适应流仍未实现。仅支持浏览器自身能解码的音视频组合，不保证所有 MP4 可播放。
- **M5 本机运维预览**：Mac App「存储」页可手动备份/恢复共享文件，也可配置仅在 App 运行时执行的每日/每周定时备份，并查看备份目录中的有界快照清单（显示清单容量，内容尚未做哈希校验）；「服务管理」提供 SMB TCP 445 只读探测。备份/恢复、清单及计划配置只能通过 Mac App 私有 IPC 触发，不暴露远程 Web API。
- **上传残留管理**：Web「偏好设置」中的管理员入口可查看当前共享目录的未完成上传、账号与写权限状态，显式取消或按 7/30/90 天期限清理残留。写入/提交期间拒绝清理，已发布文件保持不变；扫描超过安全上限时拒绝整批处理，不自动后台删除。
- **M5/P0 备份范围（已有开发版能力）**：v2 可备份共享普通文件和账号、图库/影视/任务 SQLite 与部分应用配置；单任务最多 20,000 文件项或 50 GiB，共享目录备份可恢复到隔离文件夹，应用元数据需先校验暂存，再由 Mac 所有者验证身份、停止后端后**离线激活**。已实现成功激活后的**元数据单独回退**及计划快照保留数量配置，但不等同于 Time Machine/整机灾难恢复；个人版不再要求自研文件+数据库联合自动恢复或增量快照系统；Time Machine 引导、SQLite 轻量备份恢复、SMB 安全设置引导仍需完善，原有加密和关机/重启属于可选扩展；Docker 管理为独立开发预览。[操作说明与安全边界](docs/M5_OPERATIONS.md)
- 尚未实现或未列入个人版：复杂跨卷目录移动/持久事务队列、自研联合灾备已移出个人版计划；Time Machine 覆盖状态引导、原生系统通知及有关备份/共享功能仍待完善。已实现同卷移动、跨卷安全复制及单文件安全移动、Web 故障告警、元数据回退、有限计划快照轮换和管理员清理单个回收站项。**不要把这版用于重要数据的唯一副本。**

## macOS ARM64 本地构建与运行

需要 Apple Silicon Mac、Go 1.26+、Xcode 27、Node.js 与 npm。最低 macOS 支持版本暂按 14.0 的构建设置开发，发行前需在目标版本真机验证。

```bash
cd /Users/leo/Documents/code/Lightlsle
bash scripts/build-macos.sh
open dist/LightIsle.app
```

构建脚本将安装前端依赖、运行 Go 测试、构建 Vue 与 SwiftUI，打包为 `dist/LightIsle.app` 并进行**本地临时签名**。这不是已经公证的正式发布包，不要直接分发给其他用户。

Mac App 只负责原生系统概览、首次管理员初始化、服务和存储管理；文件、图库和影视由按钮打开 Web 浏览器。**关闭最后窗口保留菜单栏与 Go Core，⌘Q/明确退出才关闭后端**；完整 GUI、登录项/睡眠、Time Machine 状态检查、Bonjour/通知到达和 Android HTTPS 真机访问仍须手工验证。

单独执行自动化校验：`bash scripts/verify-macos.sh`。M1 的历史验收记录见 [M1 状态快照](docs/M1_STATUS.md)；当前状态以 [P0 实施与验证状态](docs/P0_IMPLEMENTATION_STATUS.md) 和 [路线图](docs/ROADMAP.md) 为准。

## 技术方案

| 部分 | 拟选技术 |
| --- | --- |
| macOS 原生 App | SwiftUI + AppKit，负责初始化、控制 Go 子进程和系统管理（不依赖 WKWebView 用户页） |
| 跨端设计 | iOS 27 / macOS 27 视觉语言、Liquid Glass、共享语义 Design Tokens |
| 后端服务 | Go 1.26 + 标准库 net/http（当前）、后续 REST / WebSocket 或 SSE |
| macOS 专用服务 | Swift + 系统 Framework，受控本地 IPC |
| Web / Android 浏览器 | Vue 3 + TypeScript + Vite + PWA |
| 原生客户端 | 仅 macOS arm64，SwiftUI/AppKit |
| 数据索引 | SQLite WAL + FTS5（规划），当前为 SQLite 限量遍历与扫描式对账 |
| 媒体 | macOS `sips`（当前缩略图）、ImageIO/QuickLook/AVFoundation（规划）、必要时 FFmpeg + VideoToolbox |
| 容器 | Docker Engine API / Colima（**可选**） |
| 运行维护 | App 内启动/退出 Go 子进程、受保护本地 IPC、签名发行 |

详细见 [技术架构](docs/ARCHITECTURE.md)。

## 不做什么

- 不尝试在 macOS 上复刻 Linux Btrfs/ZFS 的存储池、RAID 或 Docker 内核功能。
- 不将 Linux、Windows、Intel Mac 作为后端兼容范围；也不为假想平台设计大量接口。
- 不宣称完全关机的 Mac 可以纯软件开机；取决于实际硬件及供电设备。
- 不承诺所有视频编码、HDR、字幕组合直接播放或都有硬件转码。
- 不允许 Web API 执行任意 root Shell；系统盘不开放远程擦除功能。
