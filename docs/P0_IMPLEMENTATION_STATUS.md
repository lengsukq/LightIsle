## 安全原则

1. 仅 Mac App 拥有首任管理员初始化、管理员重置、磁盘授权及文件备份/恢复控制权；Web API 不提供这些本机特权能力。
2. 普通用户若没有目录授权，不能读取私人文件。目录路径以相对共享根目录格式配置；`.` 表示整个共享目录。**已有成员不会自动获得读取或写入权限**，需要管理员明确授权。
3. 不覆盖已存在的用户文件；永久清理只作用于已进入 LightIsle 内部回收站的对象，并且仅管理员可执行。
4. 备份包含账号密码哈希及其他私人元数据，已清除快照中的活跃登录会话：存储目标仍应为受信任的加密磁盘，备份文件夹不得被其他普通用户读取或上传公网。
