# LightIsle 用户链路闭环审查（2026-10-25）

> 本文审查 Lightlsle 本地未提交开发工作树，不代表远端 main、真机验收或公开版本。原则：只有入口、API/IPC、权限、数据落盘、错误及恢复反馈和回归都对上，才称为**代码闭环**。外置盘和网络/签名仍须独立实际验证。修复优先于加菜单。

## 2. 本轮先查旧功能后修复的四个问题

1. **P0 旧根授权继承漏洞**：RootRegistry.Rebind 原本可以把旧 rootID 指向一块不同硬盘或同名新 inode，使该 ID 的成员授权延续到无关目录。现改为仅允许原物理目录（可改挂载路径）重新连接。换盘必须创建独立 rootID 并由管理员重新授权；原生提示和根控制测试同步修改。
2. **P1 健康历史缺口**：原先只展示即时 SMART。新增按实际磁盘枚举/不透明身份保存的 30 天有界记录，Mac 不需新增后台扫描。温度 >=60°C 或寿命已用 >=90% 提示注意；SMART 明确失败提示严重；没有报告或采集权限显示未知，不会伪装健康。历史每盘最多 360 条，只在用户手动查询时记录，不存序列号和路径。
3. **P1 手机视频遗漏**：原有 Android/iOS 只枚举照片。新增前台可选视频权限、视频和 Live Photo 视频资源列表；老用户选项默认为关，Android 后台照片授权不扩大。原片哈希和续传沿用旧路径，NAS 发现内容不一致时禁止覆盖。
4. **P1 大媒体静默忽略**：Android 前台 MediaStore 临时复制受 2GiB 限额；Android 系统后台 Worker 为资源安全仅处理每件最多 100MiB 的图片。之前这两种被跳过的原片没有明确提示。现在前台报告超过2GiB的未备份数量，后台每批报告超过100MiB/2GiB的未备份数量及补传指引，不再把扫描至结尾等同全量成功。

## 3. 不应误判完成的地方

- **多根正式开放仍未闭环**：不能仅解除开发预览开关。现有用户的旧授权、私人相册和播放进度要单独设计迁移预览与确认；额外根的定时扫描/备份和每卷通知尚未完整纳入。
- **硬盘全天候告警仍未做**：本次是点击刷新才采样的风险快照和有限历史；没有持续的 SMART 监控/通知。
- **手机媒体备份完整性仍有限制**：Android 前台原片 >2GiB、后台照片 >100MiB 和 iOS 尚在 iCloud 的原片未被自动备份；Live Photo 已保留两份原件，但客户端尚未提供完整的组合动态播放。默认 Android WorkManager 不读视频。
- 还需真实 USB 桥接、异盘备份、移动端系统权限与省电、原生通知、Finder、HLS、Cloudflare 与 Apple 签名/公证验收，不能用静态测试替代。

## 4. 验证与后续

Go 目录/授权/恢复/任务、Flutter 前台照片与新视频选项、Web 类型检查与构建、macOS Swift Release、Android Kotlin、iOS Simulator 都在本轮运行回归；最终结果以具体工具退出码为准（失败不算通过）。后续多根研发优先做可审阅的旧根→新根授权/手工资料迁移，而不是偷偷扩张现有根授权。保留本地未提交改动，不推送。

## 5. 续轮：额外共享目录自动媒体检查闭环

在继续保持 multi-root-preview 默认关闭的前提下，新增仅由 Mac App 拥有的额外根媒体调和循环：

1. Core 启动后约 30 秒开始逐根检查；每约 1 分钟检查是否到期，每个根成功后约 15 分钟再进行一次完整图库/影视索引。不使用额外常驻媒体 Worker；对原有兼容根完全跳过（仍由旧 FSEvents 调和负责）。
2. 同一时刻仅处理一根，根内部复用授权的 generation-bound lease 和原有 Gallery/Cinema.StartScan，不把新盘指向旧根编号，不覆盖用户索引。手动扫描占用时不抢占或误报成功；离线和占用会约 1 分钟后重试。磁盘恢复后对原物理目录进行完整补扫，涵盖脱机期间错过的 FSEvents。
3. 内部 tasks.sqlite 持久保存 rootID、generation、最近尝试、最近成功和粗粒度状态码；不存物理路径、磁盘序列号、用户资料或具体文件名。新 generation 的旧成功记录不可复用；Core 异常退出会把运行中状态变成 interrupted。
4. 原生 Mac 多目录开发预览的私有 IPC 列表透出每根自动扫描状态、最近成功时间。管理员主动刷新才能看到最新记录；无新的公网管理接口，没有自动格式化、自动重新绑定或备份。
5. 增加 Go 定向回归：假盘离线 → 原位置重连 → 逐根扫描成功、其他根完全不受影响；旧原根跳过、忙碌重试、同物理根代际变更、SQLite 保存失败禁止无记录后台扫描、状态持久化和异常中断检查。

**仍未解决的正式开放条件**：旧 v1 账号授权/私人相册与历史元数据迁移评审；每根独立的备份目的地和用户明确确认的自动备份计划；跨设备外接盘实际验证和正式发布门禁。绝不把“媒体索引自动更新”表述成“媒体文件已经得到备份”。
