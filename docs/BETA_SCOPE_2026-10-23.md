# LightIsle 个人版 Beta 使用范围与发布前检查

> 2026-10-23 本地 Beta 准备记录。**仅代表完成开发签名打包与自动化冒烟，不是经公证、真机断电/拔盘验证的生产版**。个人 Mac / 家庭 LAN 自行试用时，请先独立备份真实文件。仍须执行 `docs/PRODUCTION_RELEASE.md` 的正式发布门禁。

## Beta 的主要用途

- macOS arm64 上双击 `LightIsle.app` 启动 Go Core；关闭管理窗口继续从菜单栏提供 NAS，显式退出则停止 Core，不安装独立系统守护进程。
- 首次在 Mac 端初始化管理员，使用 Web 管理**当前授权单根文件目录**；支持文件上传/下载、可恢复操作、图库与影视索引、私人相册及媒体播放（格式由实际设备决定）。
- 通过内置 Web/Mac 管理界面查询卷容量、备份计划和备份/恢复结果；系统 Time Machine 的状态仅是诊断，不自动代替独立物理备份。
- 可选 LAN HTTPS 需要用户在 Mac 设置里明确打开。启用后手机可在同一网络访问。
- RootID 多根架构及隔离逻辑已有开发版代码，**Beta 默认以单根使用，暂不面向普通用户开放多根正式切换**。

## 本轮 Beta 稳定性修复

1. **媒体扫描限频与补扫**：Mac 端 FSEvents 回调合并，同目录事件至少间隔一分钟才发起自动扫描请求；根更换、Core 退出和监视器关闭时丢弃旧事件。Go Core 按图库/影院分别记录忙状态，仅对繁忙模块进行补扫，不因一方忙而反复扫描另一方。仍维持 15 分钟一次的低频核对，而非宣称已实现完整增量目录索引。
2. **缩略图缓存命中优化**：仍计算原片 SHA-256，保证“同大小同 mtime 替换”不会返回过期缩略图；缓存命中不再写多余的私有源文件，未命中时复制到渲染器专用文件并二次验证哈希、大小与 mtime。
3. **备份风险提示**：未检查 Time Machine、无备份目的地、目录被排除或无法确定最近备份时，Mac 首页提示用户检查备份。Time Machine 有最近备份的记录也不代表外置 NAS 原始文件必定受到保护。
4. **影视资料来源**：优先本地 NFO 和 TMDB，保留手动确认/不覆盖原片的行为。

## 豆瓣网页搜索候选（实验性备用）

Mac Web 的影院详情内可以**直接搜索并显示**豆瓣电影网页采用过的搜索建议响应，无需跳转，不需要让用户输入豆瓣账号或 Cookie。管理员输入片名并选择候选后，后台再次核对候选，最多使用**片名、年份、类型**进行匹配，保留手动片名、简介、评分、海报和观看进度，**不会假装搜索建议提供了正式评分、简介或图片**。

该接口**不是豆瓣官方开发者 API**，网站可能拒绝访问、变更响应格式或限制第三方使用，失败时不自动重试、绕过风控、强制登录或爬取详情页。不批量建立豆瓣元数据库。豆瓣当前法律声明对第三方使用其条目资料有限制；需要对外发行这种集成前应获得相应授权，否则应关闭这项实验功能或只保留正式授权的数据源。TMDB 与本地 NFO 的体验不受该接口不可用影响。

## 本地构建与运行（开发机）

在 Apple Silicon Mac 的 Lightlsle 仓库根目录执行：

```bash
bash scripts/build-macos.sh
open dist/LightIsle.app
```

该脚本生成的是 **ad-hoc 签名的开发测试 App**。它会先执行 Web/Go/Swift 构建与内置自动化冒烟。不要将它当作已经签名、公证的公开发行包；运行前应退出当前 LightIsle 实例，确认用户数据目录备份独立存在。

## 仍未通过的发布级门禁

- 双物理硬盘拔插/断电、满盘、大文件恢复以及跨卷数据安全的真实设备验收。
- 不同 macOS 版本、FileVault/自动登录/睡眠唤醒、Mac 登录项与本机通知的真实 GUI 验收。
- Developer ID 签名、Apple 公证、Gatekeeper 干净设备校验及发布 QA 规定的长时运行等证据。
- 豆瓣网页的实时搜索可用性、授权和上游稳定性**不能靠模拟测试推断**；在线使用失败时应清晰降级。

## Beta 升级前检查（本机、只读）

1. 先完全退出 LightIsle，并单独备份 **LightIsle 私有数据库和真实 NAS 原始文件**；确保原件和备份保存在不同物理磁盘，保留旧 App 以便回退。
2. 运行下列只读预检。它会检查已存在的 SQLite 文件是否可读取、数据库基础完整性及文件类型异常；**不会修复数据库、迁移结构、生成备份或访问你的共享原片**。

```bash
python3 scripts/beta-upgrade-preflight.py --data-dir "$HOME/Library/Application Support/LightIsle"
```

3. JSON 结果为 `checks_passed_not_backup_verified` 仅表示数据库基础检查通过，**不代表备份覆盖已验证**。若 `status` 为 `blocked`、出现 SQLite 错误或源数据卷离线，请停止升级并保留原数据。升级后的 App 完成首次登录、文件、图库、影院和恢复入口检查后，再考虑移除旧版。

### 本轮修复：影视资料匹配持久性

- 视频文件名重扫不再覆盖用户已确认的片名、年份。影片表新增 `title_source`、`year_source`，与简介/评分的 `metadata_source` 分离；已手动命名的标题保留 `manual` 来源。
- TMDB、NFO 的已确认片名会持续保留；豆瓣建议的年份独立保留，不以搜索候选伪造完整简介、评分和海报。旧 Beta 已标记的来源在启动迁移时进行兼容回填。
- Mac 端 Time Machine 查询结果只属于发起检查时的共享根，切根立即作废；无法据此断言真实外置 NAS 源卷已经备份成功。
