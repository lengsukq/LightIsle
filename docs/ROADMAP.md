## 开发范围

长期产品约束（macOS arm64、仅 v2、每盘独立 100 GiB、仅配置备份、不自研联合灾备）在 [PRODUCT](PRODUCT.md) 和 [ADR 0003](adr/0003-personal-homes-and-quota.md) 统一维护；**此处只列仍需完成的工作**。当前账本仍为 `enforcement=pending`。家庭邀请 Beta 使用同一候选构建验收当前功能，所有发布阻断项通过后一次交付。

## 完成定义

1. 入口、角色授权、物理根代际、SQLite/文件落盘、取消、错误恢复及自动化回归相互一致。
2. 无法确定身份或容量时安全拒绝，而非自动改盘、删除原件或释放不确定预占；存储配额不得因管理员写入绕过目录所有者。
3. 代码级测试和真实硬件/第三方服务验证**分别记录**。构建成功不代表生产验收通过。
4. 新状态只更新 [STATUS](STATUS.md)，独立设备证据记录在 [验收清单](DEVICE_ACCEPTANCE.md)；长期架构调整写 [ADR](adr/0003-personal-homes-and-quota.md)。

## 远期可选（不作为 Beta 验收任务）

可根据实际家庭使用需求再评估：可撤销的通用第三方 API Key、云端异地配置快照与公有云/异地原始文件加密增量同步（受控 ZIP 在线解压、同卷 APFS `clonefileat` 写时复制、Apple Live Photo 全端配对播放、智能回忆与人物自动只读共享、`.strm` 流媒体直链、Tailscale 零配置双栈组网、设备级会话管理、`pmset` UPS 断电联动守护、4 款内置静态轻应用模板及 Apple Vision 本地 AI 相册均已在代码中完成全端闭环，按上表推进真机验收）。仅作为候选，**没有完成或发布承诺**，不得替代上表的存储安全与真机验收。

## 不在个人版范围

不自研 RAID/ZFS/Btrfs、企业级 HA、逐根文件自动备份、跨盘自动迁移、独立开机常驻服务器、完整脚本沙箱。复用 macOS、APFS、SMB、Time Machine、SQLite 和用户主动安装的可选依赖。
