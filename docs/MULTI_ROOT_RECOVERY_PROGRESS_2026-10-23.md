# 多目录与恢复预览续做记录

本记录基于用户更新后的工作区及 [最新个人版范围](FNOS_PARITY_PRIORITIES.md)。三名子代理统一使用 **GPT-6 Luna / max**，先复审、再按文件归属实施；主代理负责集成与交叉复核。未提交、未推送；未下载外部资源，未操作真实 NAS 文件、系统 SMB、Time Machine 配置或真实 Docker。

## 本批实现

| 范围 | 已实现行为 | 开放边界 |
| --- | --- | --- |
| 物理目录身份 | 修正实际 diskutil plist 解析；卷 UUID、inode、创建时间与目录句柄共同核验；路径换盘及 A→B→A 替换不能冒充原目录 | 老 path-only 配置保持离线，含默认路径的旧配置也需所有者重新选择；只有首次安装自动建立默认目录 |
| 登记可靠性 | 固定临时文件改为独立随机临时文件；配置发布后同步失败时暂停访问，重启核对；不得共享私有数据库目录或其祖先 | 最大 16 根；离线不切换到其他目录，移除登记不删除文件 |
| 根 API | `/api/v2/roots/{rootID}` 下隔离文件、搜索、ZIP、上传、分享、图库、影院、权限、任务与告警；先根授权再初始化服务；请求和扫描持租约 | CLI `-multi-root-preview` 默认关闭；普通安装继续使用 v1 单根 |
| 撤权与重绑 | 分享写事务内复核账号/会话/授权；token 绑定根及代次；旧代次写请求拒绝；成员无法通过媒体编号判断未授权文件是否存在 | 重绑不把旧媒体整理关联到新盘，旧分享失效；进行中的请求、扫描和备份阻止重绑/移除 |
| Web | 开发预览下可显式选择额外目录；各 URL、权限、媒体与上传续传均带根范围；切换取消旧请求并等待上传结束，清空旧弹窗/列表 | 默认保留“原共享目录（兼容）”；不自动迁移原授权、私人相册和播放进度，不把旧库显示为空的新库 |
| 原生预览管理 | 仅 `LIGHTISLE_MULTI_ROOT_PREVIEW=1` 开发环境显示额外目录登记/重选/移除及逐目录备份状态；仅私有父进程管道可操作 | 不提供 HTTP 登记/备份提权入口；预览期间原共享目录不更换；请求 ID 防止旧响应污染当前状态 |
| 多根元数据 | 每根 gallery/cinema/tasks 数据库平铺保存，按根/代次隔离索引和缓存；导出/恢复/回退白名单限定注册根 | 最多 16 根、55 主文件、64 主文件清单预算、192 回退含 sidecar 文件、2 GiB 元数据总预算；不导出浏览器会话或分享能力 |
| 备份绑定 | 新根快照额外记录 logicalRootID 和 rootGeneration，原 SourceRootID 物理语义保留；根及目的地重新核验，异步任务全程持租约 | 不提供多根自动计划；旧单根计划保留。换根/旧代次/旧登记簿快照不能直接作为新根恢复 |
| 恢复预览 | 只读计数显示账号、授权、私人相册/收藏、手工资料与索引/任务差异；未知旧表显示未知；确认时绑定已审阅 manifest 摘要 | 原生所有者确认后停 Core 再应用；不覆盖原片，保留旧数据库；不是文件与多库同一时点的联合恢复 |

## 本轮自动化证据

逐模块测试已覆盖同名路径跨根读写、搜索/ZIP 权限、上传状态/完成/取消、相册/收藏/影视编号隔离、重绑与旧链接、任务取消、配置同步失败、路径替换及未授权请求不创建数据库。恢复覆盖平铺多根导出、暂存校验、摘要不匹配拒绝、激活/回退、会话与分享清理。本批后续已通过整包测试；最新 Beta 3 的构建、race 和打包验证详见 [缺口复审记录](BETA3_REAUDIT_2026-10-23.md)。此前临时浏览器验证了管理员 A/B 根同名文件内容隔离、切根关闭旧详情、仅 B 新建目录以及只读成员只见授权 A；不是正式多盘或多设备验收。

## 仍未完成

- 多目录正式开放前，完成旧授权、私人相册/收藏及播放进度的明确迁移流程；额外目录恢复出的元数据当前保持隔离，需继续接入原生统一恢复预览入口。
- 多根计划及卷相关通知汇总仍未接；当前原生自动维护沿用原共享目录，额外根按需手动扫描。
- 真实双物理盘拔插/满盘/重挂、Time Machine 源卷覆盖与恢复、关窗/注销/睡眠唤醒、Touch ID 和系统通知到达、大图库与长时运行均需单独验收。
- Developer ID、公证、干净机器安装及现有发布 QA 门禁未完成；开发包不代表正式发行。

通用持久化传输调度、自研增量备份和联合灾难恢复不在个人版范围。本批保留已存在的实验源文件，但未把实验传输队列接入启动或用户操作。
