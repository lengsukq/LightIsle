# LightIsle 个人版 Beta：存储设置入口与外接磁盘选择计划

## 目标与原则

用户在 Mac 插入外置 SSD/HDD 后，应在「数据与存储」中**直接看到磁盘、识别当前 NAS 存储位置，并能从磁盘卡片选择一个专用目录**，无须猜测共享根目录功能藏在哪里。继续复用 macOS 文件系统、系统文件选择器、原有 Go Core `share set` 及卷身份验证，不创建 RAID、存储池或新的磁盘挂载服务。

当前个人 Beta **只有一个生效的共享根目录**。不同时开放多根目录、分媒体库目录、挂载/格式化磁盘、自动搬迁既有文件。开发多根预览仍单独隔离。

## 实施顺序

1. **入口可发现性（P0）**：在存储页突出显示当前完整路径、所属系统卷、可用空间和在线/离线状态；避免仅显示 `SharedFiles` 让用户误认已使用外置盘。
2. **可选磁盘卡片（P0）**：把已挂载卷列表提前到存储页上半部。对 macOS 提供的、位于 `/Volumes` 下的可写外置卷提供「在此磁盘选择目录…」操作；选择器定位到所选卷，可创建专用 `LightIsle` 文件夹，不自动共享整盘，也不自动格式化或删除数据。只读、系统卷不能通过磁盘快捷入口直接切换，但原有「更改目录…」仍支持合法的用户主目录位置。
3. **安全切换与反馈（P0）**：确认框清楚说明「原目录保留、不移动文件、媒体库会重扫、既有分享/上传需核查」；切换期间禁止重复请求，等待 Core 返回结果后显示成功/失败。失败不把仍在线的原目录误报为离线；切换时不影响管理员身份。后端继续校验真实卷身份和路径，绝不通过 Web 提供任意宿主磁盘配置接口。
4. **引导（P1）**：在私人文件页突出「配置存储」入口；首次使用和已配置用户都能自然找到。将选中的磁盘/目录关系、单根限制和迁移边界写到文档。
5. **回归**：覆盖路径前缀边界（相邻挂载名不能误认）、最长匹配卷、外置卷可选性、当前存储归属；Swift 编译、Go 测试及现有应用构建验证。所有测试不访问、修改真实外接磁盘原片。

## 验收边界

- 当前目录应精确展示为 `/Volumes/<卷名>/<目录>` 或主目录内合法路径，卷未在系统采样中出现时明确说明无法确认所属卷。
- 只读磁盘不能发起快捷切换；关闭或更换磁盘时不能因路径同名就暗中重绑定。
- 原有共享根的文件、回收站、媒体索引和管理员账号在本次 UI 切换中**不执行删除或迁移**，旧数据保留在原目录。只有 Core 确认切换成功，才更新当前目录 UI。
- 若更换目录时遇到正在备份、跨卷操作或离线情况，阻止从本页发起切换并显示可操作的提示。
- 不将模拟测试视为真实外置盘断开、睡眠和系统权限的真机验收。

## 后续（本轮不做）

统一文件 / 照片 / 影视独立存储位置及完整多根权限、媒体与备份切换，需要独立迁移和真机验收；这不是本轮 P0/P1 的范围。

## 本轮实施记录

- 已改造 Mac 原生「数据与存储」：共享路径、所属卷容量、可用磁盘快捷选择、目录切换状态与失败提示。把可用磁盘列表提升到迁移、备份等高级功能之前，私人文件页增加直达存储设置按钮。
- macOS 系统文件选择器限定快捷入口的磁盘范围；拒绝直接选整盘根目录或跨盘符号链接。对已配置根的切换展示原目录、目标目录、数据不迁移及媒体重新扫描提示；更改失败保留 Core 当前在线目录。
- 新增 `StorageVolumeSelection` 路径边界回归并接入 `build-macos.sh` 和 `verify-macos.sh`。现有 Go Core 目录授权和物理身份校验未放宽。
- 本地执行 `bash scripts/verify-macos.sh` **通过**：Go 全包测试及 vet、Swift Debug 构建、Swift 原生检查、Web 25 项测试与生产构建、发布 QA 单元检查。没有测试真实外置硬盘，更未执行格式化、删除或旧数据搬迁。
- 尚需真机手动确认：外置盘选择器的实际权限、USB 卸载/重挂、同名替换盘、满盘、磁盘被其他进程占用、切换期间的大型上传与多端旧连接处理。本轮没有正式签名与 Apple 公证。

## 收尾续做

- 修复「外置盘已卸载，但原路径仍位于 /Volumes 下」时被错误识别为系统盘的边界；增加卸载卷、相近磁盘名的纯 Swift 回归用例。
- 存储切换只接受和预期目标目录相符的 Core 路径回执；30 秒无确认时按「结果不明」提示人工核查，不虚报成功。配置持久化可能存在不确定结果时，明确要求彻底退出重启核实，而非承诺原目录永远不变。
- 构建产物为 `dist/LightIsle.app`，由本地 `bash scripts/build-macos.sh` 生成开发用 ad-hoc 签名包；涵盖 Go、Web、Swift 构建和随包冒烟。人工 USB 插拔、跨物理卷与真实已有 NAS 数据恢复仍未验收。
- **工作区共存规则**：与本轮存储改造无关的 Flutter 等其他任务修改必须保留，不纳入存储功能提交或打包结论。
