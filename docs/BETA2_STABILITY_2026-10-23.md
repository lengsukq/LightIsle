# LightIsle v0.1.0 Beta 2 · 稳定性与日常使用

> 本地开发版本，Build 2。只适合在已备份个人数据的 Mac 上试用。此版本不等于签名公证发行版；不代表已通过外接硬盘断电、跨盘拔插、72 小时压力或 Android 真机检查。

## 本轮真正交付

1. **共享存储掉线状态同步**：Mac 每 30 秒经私有 stdin IPC 发送 `share status`，Go Core 使用已有物理目录身份绑定报告在线/离线。查询不重连、更不允许同名磁盘自动接管；掉线后停止 FSEvents、清空原路径在线状态、取消待扫描任务，并通过已授权的本机通知提示。在 Mac 设置中点击“重新连接”后，原有 `Reconnect` 必须再次验证原目录身份。
2. **Core 启动超时**：20 秒未收到 `LIGHTISLE_READY`，由 Mac 所有者 App 按现有受控流程停止未就绪 Core，回到明确的错误与手动重试状态；不进行崩溃后无限重启，也不绕过数据库恢复的失败封闭机制。
3. **进程输出防护**：Mac 改用字节级 `CoreLineFramer` 接收 stdout，以完整的 UTF-8 行解码，不会因一次 read() 切开中文字符而丢失路径/告警文字；单行限制 256 KiB，超大行丢弃并从下一行恢复，每次重新启动 Core 清理旧消息尾部。
4. **此前 Beta 的稳定性代码沿用**：文件变更事件合并/限频、图库和影院扫描繁忙补扫、缩略图避免不必要的源文件临时复制、影视确认标题/年份重扫保留、Time Machine 切根诊断失效、仅检查数据库的升级前预检，以及豆瓣网页搜索建议的实验性备用匹配。

## 如何在本机检查

```bash
cd /Users/leo/Documents/code/Lightlsle
bash scripts/build-macos.sh
open dist/LightIsle.app
```

构建脚本会执行 Go、Web、Swift、打包内置测试，并新增两项回归：

- `tests/test_storage_status_ipc.py`：仅在临时目录模拟共享根被移走、原路径出现同名替换目录；Core 应先报告在线，再报告离线，不接触实际 NAS 文件。
- `tests/CoreLineFramerCheck.swift`：完整中文行的逐字节到达、256 KiB 异常行跳过和前一次 Core 输出重置测试。也包含在 `scripts/verify-macos.sh` 中。

## Beta 2 仍不包含的承诺

- **不会自动重连磁盘**，拔盘/换盘后必须由 Mac 所有者确认并点击重试。
- **不会自动恢复损坏的 SQLite 或文件**；备份验证、离线激活和回滚继续由现有管理员入口负责。
- **不提供系统级常驻服务**；关闭主窗口留菜单栏，完全退出/用户注销后 Core 停止。
- **不提供正式发行升级器或公网自动穿透**。开发包采用 ad-hoc 签名；Developer ID、公证和真实硬件验收仍是正式发布门禁。
- **不默认开放多根目录 Beta API**；保持单共享根个人版 Beta 的安全边界。
