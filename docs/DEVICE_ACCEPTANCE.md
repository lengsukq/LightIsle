## 下载中心（P1）

- [ ] 部分证据（2026-10-25）：`TestRealAria2DownloadLifecycle`（aria2 1.37.0 真进程）覆盖 本地 HTTP 下载→发布、同名改名 `(2)`、授权撤销拒发布、慢任务取消→重试→删除记录。
