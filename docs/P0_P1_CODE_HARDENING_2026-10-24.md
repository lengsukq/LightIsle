# LightIsle 个人版 P0/P1 代码级可靠性收尾（2026-10-24）

本轮在原有代码四批提交推送后继续实施，不涉及真实 NAS 盘格式化、移动/删除原片或生产签名。产品目标仍为 macOS arm64 上的个人 NAS 管理层，不建立企业事务引擎。

## P0：上传低空间保护

- 分片实际写入前对已校验的 staging 文件描述符使用 `Fstatfs`，保证检查目标是该分片真实所属卷，避免依靠用户可替换的挂载路径。
- 留出 64 MiB 基础空间供应用 SQLite / 文件系统元数据使用。空间不足拒绝追加并以 HTTP 507 `insufficient_storage_space` 通知客户端。
- 低空间拒绝不会提前修改已提交偏移或发布残缺的目标文件；磁盘空间释放后可用原会话继续。
- 这不构成对其他并行写入的空间预留；已在写入流程中的 I/O 失败依赖原有同步/回滚机制处理。

## P1：影视播放进度收尾

- 按共享根代次与影片 ID 串行写入进度，避免较早的请求延迟返回后覆盖新的位置；相同影片仅保留待发送的最新快照。
- 请求失败保留内存中的待重试快照，在影视页显示错误和手动重试；关闭播放器后仍可恢复，切换页面/重新载入则不承诺持久离线队列。
- 播放器卸载前发送最后一次进度，使用小请求的 `fetch keepalive`；远端账户/网络已不可用时仍可能失败，不把失败伪装成已保存。

## 仍需验收

- 真正双物理盘的拔盘、满盘和恢复；重启/崩溃与系统并行写入竞争测试。
- Android/iOS Bonjour、背景备份和锁屏/省电限制真机验收。
- 正式签名、公证、Gatekeeper 及 72 小时持续运行；多根目录仍为开发预览。
