## 已验证的本轮实现

- 图库、影院局部清理使用 SQLite 字符长度处理目录前缀，避免 Go UTF-8 字节长度与 SQL 字符位置不一致。中文加 emoji 目录回归同时验证相邻前缀目录、收藏、相册和观看进度保留。
- 成功 `share set` / `share retry` 后立即请求媒体核对；不依赖新 FSEvents 监听器追溯离线期间变化。临时根回归覆盖离线期间新增照片与影片。
- Mac 定向扫描路径包含反斜杠或逃出共享根时回退全量。新增 Swift 范围测试已接入正常构建/验证脚本。
- TMDB、豆瓣候选应用前核对当前文件快照，数据库更新还约束原尺寸与修改时间。两个本地模拟上游测试覆盖请求等待期间原片被替换并重扫，旧候选返回 `ErrAssetChanged`。
- SHA-256 接口保留账号与目录授权，进程内最多两个并发校验，繁忙返回 `429 file_hash_busy` 和一秒重试提示；不积累等待队列。读取上限为初始尺寸加一个探测字节，尺寸超过 2 GiB 返回 413。回归覆盖跨 API 共享预算、取消释放预算、增长文件只读两字节的确定性模型、稀疏大文件拒绝。
- Android 原生响应读取使用 API 24 可用的有界 `InputStream.read` 循环，避免 API 33 才有的 `readNBytes` 在旧手机崩溃。本地缓存 Kotlin 编译器回归覆盖空响应、短读/零读、64 KiB 上限和 I/O 错误，不下载工具。

## Android 功能闭环

- 前台原生照片读取带唯一请求编号；暂停、离开前台和页面销毁会取消复制，迟到临时文件也释放。快速恢复发生在旧任务结束前时排队一次续跑；手动暂停清除此队列。无法中断的已发送请求结束前显示“正在暂停”，不提前宣称停止。
- Android 配置通道使用进程内 FIFO 队列；Dart 登录、退出与替换会话串行等待原生 end/bind，旧会话结束不会清除新会话。登录回调被等待，组件销毁和过期登录结果受保护。
- 加密后台配置带递增代次；WorkManager 输入仅含代次，不含凭据。旧 Worker 在网络与状态提交边界检查代次，旧 401/权限失败不能关闭新账号任务；扫描游标、媒体库版本、上传续传状态按代次隔离。
- 原生临时复制支持 CancellationSignal，Worker 停止时同样取消；prepare 成功但尚未投递页面时仍保留请求登记，Activity 销毁/投递失败释放临时副本。
- 后台每轮独立限制三页和 30 张；空结果但非空下一页游标仍计入页数，持久化位置后停止，防止异常媒体记录导致无界循环。前台每轮最多 400 张；均不将批次结束写成全库完成。后台单张超过 100 MiB 留给前台处理。
- 上传完成使用已认证远端 SHA-256 与完整原片摘要核对；发现已存在内容不一致时停止并提示人工检查，不覆盖原文件。后台约六小时的周期由系统安排，初始大相册快速补齐调度仍是下一批缺口，不能宣称大库自动备份体验已完成。
- 额外打包回归已验证：不同根同名文件返回各自 SHA-256，只读成员可核对本根文件，未授权根返回 404，不能把摘要接口变成内容探测入口。
