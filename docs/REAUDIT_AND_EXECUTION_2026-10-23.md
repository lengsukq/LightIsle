## 本轮审查后分配的工作

| 工作包 | 确认的问题 | 分工与交付 |
| --- | --- | --- |
| 恢复可靠性 | 旧数据库移入回退目录后没有同步该目录；仅剩会话清理标记时 list/inspect 误报恢复结束 | 原生/备份子代理：跨目录同步；区分元数据事务和会话清理；损坏当前账号库仍可离线回退；打包恢复测试 |
| 跨卷数据保护 | 校验结束到移入回收站之间，外部进程替换或改写源文件，可能移动未经校验的版本 | Core 子代理：校验后复查 fd/路径；对实际移走对象再校验；不覆盖恢复，失败保留回收站记录和目标副本 |
| 分享撤权 | 发链接的预检查与 INSERT 分离，撤权后仍可能插入旧能力，重新授权后复活 | 主代理：在同一写事务中重新检查会话、账号和字面目录授权；并发撤权/退出/停用回归 |
| 私人相册 | 成员操作位于详情弹层背后，选中状态清空使 Web 无法加入/移出 | Web/媒体子代理：将操作放进详情，隔离不同图片/相册的异步响应，保留只读成员的个人整理能力 |
| 影视详情 | NFO 旧响应替换新影片详情；带远程 URL 的坏海报不显示占位 | Web/媒体子代理：只更新对应影片，失效请求不能重新打开详情，失败海报回退 |
| 告警状态 | 容量探测失败被当作低空间恢复；切换历史时在途请求返回旧筛选结果 | 主代理修后端未知状态保留；Web 子代理修请求取消与刷新隔离 |
| 下载审计 | 公开下载在发送前记录成功，416/断线仍成功，写审计失败无提示 | 主代理：根据真实响应状态与写错误记录，持久化失败产生诊断日志；不记录文件名或分享密钥 |
| Docker 资源边界 | 输出先无界写临时文件、再全量读入内存，最后才检查 1 MiB | 原生子代理：有界双流读取、超限/超时终止和本地伪命令测试 |

以上处理已确认的用户流程与可靠性问题，不代替后续功能建设。

## 下一批优先顺序

1. **多根模型与权限闭环**：逐根隔离文件、上传、分享、媒体、任务和备份；原共享目录保持兼容，完整迁移与验收前只开放开发预览。
2. **轻量数据库恢复**：校验一致性 SQLite 导出、提供数量差异预览、所有者确认后离线激活、保留旧库与手工重扫；原始文件使用独立备份与 macOS 原生备份兜底。
3. **媒体日常体验**：增量索引、稳定分页、年月跳转、影视剧集；转码先确定本机方案、所需资源与分发约束，需要下载时单独说明具体资源。
4. **运维与升级**：原生通知、诊断导出、版本化迁移与升级失败回退；Docker 应用目录等可选能力在基础存储可靠性之后推进。
5. **真实验收**：双物理卷拔插/满盘/同路径重挂、Touch ID、睡眠唤醒、规模素材、72 小时稳定性、Developer ID/公证与干净机器安装。
