## 尚存缺口：19 项

以下按独立交付单元统计，避免将同一功能拆成几十个假任务。其中 **P0 4 项、P1 9 项、P2 6 项**。P0 表示生产就绪阻断或重要数据可靠性工作；P1 为明显缺失的日常功能；P2 为可选扩展。

| 编号 | 优先级 | 具体缺口 | 当前边界与验收方向 |
| --- | --- | --- | --- |
| 1 | P0 | 跨磁盘可恢复的**移动** | 单文件日志化移动已实现（校验后只移入回收站）；仍缺**目录级移动**、断点续执行、真实拔盘/断电验证；不能宣称全量完成 |
| 2 | P0 | 文件与数据库的**联合灾难恢复** | 目前共享文件恢复至隔离目录、元数据另行激活/回退；需版本绑定、数据一致性和可回滚恢复 |
| 3 | P0 | 正式签名、公证及可靠升级/降级 | 有本地构建/临时签名和发布校验；缺真实 Developer ID、公证、升级迁移与失败回退 |
| 4 | P0 | 物理硬件与长期稳定性验收 | 缺真实双卷拔插/同路径重挂、满盘/断电、10 GiB 数据、72 小时运行及干净机器实测 |
| 5 | P1 | 多共享根目录与按根授权 | 当前以单共享根目录/其子目录授权为主，需要多卷共享切换与相互隔离 |
| 6 | P1 | 持久文件复制/跨卷传输队列 | 跨卷复制有取消但无持久任务、重启继续、残留暂存治理和 IO 限流 |
| 7 | P1 | 存储健康/离线/空间不足/备份失败通知中心 | **已接入持久应用内通知**、阈值、恢复状态、去重与管理员确认；仍缺原生 macOS 通知授权、阈值设置和真机验证 |
| 8 | P1 | 每账号私有相册和收藏 | **私人收藏与私人相册均已独立建表并接入 Web**，旧共享数据不受影响；仍需账号清理政策、旧数据迁移规则与真实多账号 GUI 验证 |
| 9 | P1 | 图库大数据量和完整媒体元数据 | 月份分组虚拟时间线及自动加载已实现，有 10 万条合成布局测试；仍缺真实 10k+ 素材、增量索引检查点、稳定游标及多格式矩阵 |
| 10 | P1 | 不兼容视频的服务器端转码和音轨支持 | NFO/TMDB **手动资料匹配**已实现；播放仍仅直放/探测，没有完整 MKV/MOV/HEVC 转码、音轨切换、VideoToolbox/HLS，影视资料真实接入也未验收 |
| 11 | P1 | 备份加密与增量版本 | 现有全量快照和保留策略；缺端到端加密、增量去重、密钥恢复及恢复链校验 |
| 12 | P1 | 账户、分享、文件操作的持久审计 | **已接入 SQLite 90 天 / 20,000 条审计与管理员 Web 查询**，覆盖主要成功/失败写操作及分享下载；仍缺完整权限拒绝监控、日志防篡改与生产压力验收 |
| 13 | P1 | 完整 GUI/浏览器兼容性和可访问性回归 | 需要 Mac Touch ID 真实流程、Android 浏览器 HTTPS、键盘/屏幕阅读器、休眠唤醒和操作失败状态实测 |
| 14 | P2 | HTTP(S) 远程下载任务中心 | 只有用户上传与浏览器下载；缺服务器拉取、进度、断点、队列与限额；BT 尚未设计 |
| 15 | P2 | Docker/Colima 与应用中心 | **本机管理初版已补**：原生 Mac 页面具备 Docker Desktop/Colima 状态、容器启停与日志、镜像列表/手动拉取、已有 Compose 项目控制与新项目配置导入、卷/网络列表与安全创建，以及镜像源备份后配置；仍缺完整应用目录、Compose 版本升级、自动更新、容器/卷/网络高级写操作与真实引擎验收（详见 `docs/DOCKER_MANAGEMENT.md`） |
| 16 | P2 | SMB 原生安全配置入口 | 只有状态检查/打开系统设置，不具备受权后的启停/共享授权自动配置 |
| 17 | P2 | 受权系统电源管理 | 目前 App/Go 服务进程可以退出或重启；没有经原生鉴权的 macOS 关机/系统重启 |
| 18 | P2 | 全局内容/媒体全文搜索索引 | 当前文件名限量搜索、影视/图库独立搜索；无统一索引与正文搜索 |
| 19 | P2 | 完整多语言与无障碍审查 | 页面仍有较多中文硬编码、各端文案与动态辅助说明需系统性完善 |

## 推荐推进顺序

优先验收本轮新增功能的真实 Web 场景（登录、成员重置、创建/撤销分享、过期与重新授权、文件变更时的响应）。之后先设计跨卷持久任务队列和可恢复移动的失败模型，再设计文件+元数据联合恢复。两项涉及原数据删除或数据库切换，不能直接以“复制成功就删源”实现。

发布前必须按 `docs/PRODUCTION_RELEASE.md` 中的门禁逐项完成。当前代码 **只证明实现与自动化测试覆盖，不证明真实多盘断电、正式签名、公证或长时间稳定性通过**。
