> **2026-11-07 个人空间、图库相册与影视刮削闭环（工作区）**：
> 1. **私人回收站受控永久清理与账本释放**：私人目录所有者或管理员永久删除回收站项目时，先验证回收站暂存对象身份（`device + inode`）与账本中的 `StorageObjectIdentity` 完全一致，仅在文件/目录内全部账本记录均可一对一核实且物理清理确认完成、未发生同路径换盘时释放对应配额；历史无身份记录、外部未入账文件或换盘异常会拒绝清理并保留原件与账本。
> 2. **私人目录文件夹重命名/同根移动与受控 ZIP 在线解压**：支持私人目录在同存储根、同一所有者内重命名或移动（含原子更新目录前缀账本与防覆盖冲突）；支持将 `.zip` 归档在线解压到同级独立子目录（拒绝路径穿越、符号链接及超限归档，私人目录先按解压总字节预占额度并在逐项核实身份后提交账本）。
> 3. **WebDAV 私人目录受控读写**：默认根下已获授权的私人目录（`Users/u<ID>/...`）支持 WebDAV `PUT`、`MKCOL`、`DELETE`（移入应用回收站）及同根同所有者重命名 `MOVE`，写入与覆盖均走同一物理根代际配额账本与回收站身份登记；跨所有者移动与私人目录 `COPY` 仍安全拒绝。
> 4. **受控软链接共享文件夹相册与多维 EXIF 筛选**：文件夹相册所有者可将相册共享给同盘有照片目录授权的成员（默认只读、可选可写），在接收方 `Users/u<member>/photos/` 下创建指向 `../../u<owner>/photos/<album>` 的受控相对软链接；图库扫描、缩略图/原图读取及授权可写上传均在服务端校验 `shared_folder_albums` 授权，成员向可写共享相册上传时计入**相册所有者**在该盘的配额账本。图库新增按相机型号、是否含 GPS 定位、拍摄日期范围及 `/api/v2/photos/facets` 聚合的组合筛选。
> 5. **影视扫描后自动增量刮削与「待匹配」筛选**：当已配置 TMDB Token 且扫描完成发现尚未尝试刮削的新增影视时，自动衔接后台限速增量刮削；`GET /api/v2/cinema` 新增 `kind=unmatched` 与 `scrapeState` 字段，Web 与 Flutter 影视页新增「待匹配」分类入口与未匹配标识。**以上均为工作区代码与自动测试结果，不代表真实多盘、Finder/Infuse 或手机真机验收完成；配额整体状态仍保持 `enforcement=pending`。**

> **回收站对象身份（工作区）**：新移入的文件或文件夹在身份可核实时，将对象身份保存在本地回收站日志中；移入后、恢复前和永久清理前检查该对象，若已被替换则拒绝继续并提示检查原位置与回收站。批量操作遇到身份变化时停止后续条目。历史日志及无法核实身份的对象沿用旧行为，不推测或补造身份。检查和文件系统操作之间仍可能受到其他本机进程干扰，不等同原子删除或实盘验收；历史无身份记录或身份发生冲突的私人回收站条目继续拒绝清理。

> **容量账本文件身份基础（工作区）**：普通上传从写入时持有的文件句柄获取身份；分片上传核对已发布文件与暂存日志记录的身份；受控复制核对暂存文件与最终文件身份。身份可确认时与容量账本同一事务保存；私人单文件重命名前核对已知身份、移动后核对原文件身份，并在提交账本时检查身份没有变化，中途不确定则保留预占供检查。新增内部账本核对操作：按原路径范围读取文件身份，提交时只对明确列出的身份、所有者和大小完全相符的记录清账，任一项变化则整体回滚；不会按目录前缀直接删除新文件的账本。身份不可确认或旧记录没有身份时保留未知，不从路径猜测；外部进程仍可与检查并发，不能把软件测试当作物理设备验收。这为安全清理提供了身份校验基础；私人回收站受控永久清理现已接通身份与账本核验，但在外部写入通道全部闭环与实机复核前，**配额整体状态仍保持 pending**。

> **删除与恢复的换盘反馈（工作区）**：单项移入回收站、恢复、共享项目永久清理在操作后重新核对物理根；若发生同路径换盘，提示操作结果不确定，要求回原硬盘检查目录和回收站。批量删除在发现身份变化后停止后续操作，逐项区分结果不确定与未执行，Web/Flutter 显示相应提示。同一 Core 进程内，同一存储根的回收站移动、恢复、永久清理及跨盘移动的源文件落入回收站会互相等待，避免恢复回滚期间被另一操作删除记录；即使两个管理器分别打开同一目录也适用。外部进程不受该保护约束。故障注入以临时目录模拟换盘，尚不代表真实外置盘拔插验收。

> **缺失媒体处理反馈（工作区）**：关联或放弃成功后立即移除已处理项，重新读取列表时使更早的慢请求失效；读取失败保留其余已知记录并提示结果不完整。请求结果不明确时先刷新核对，避免把未知结果称为失败。页面打开时跟踪正在进行的检查，结束后自动刷新；Web 标签隐藏或 Flutter 应用进入后台时暂停查询，返回后恢复。Flutter 还记录根选择变化的序号，切走后再切回同一根也不会继续旧确认操作。关联及放弃在事务中复查原硬盘、目录归属和写权限，提交前检查失效时回滚；检查与提交之间仍存在无法跨数据库和物理设备原子消除的短暂竞争。Web 并发回归和 Flutter 静态检查通过；新增 Flutter Widget 用例尚未运行，真实设备验收留待用户完成。

> **配置恢复软件演练（工作区）**：隔离测试在两个模拟存储根中完成配置快照、校验、离线激活和回退；核对成员只读授权、各根独立额度、未完成预占、文件身份、私人相册及旧会话失效，并确认原文件不随配置恢复被覆盖、同路径替换目录不继承原根身份。测试使用临时目录和模拟身份提供者，不是独立物理介质、断电或真实硬盘验收；原始文件仍需另行备份。

> **上传清理与预占（工作区）**：用户取消、管理员取消和手动过期清理在移除暂存后重新核对原硬盘和目标文件，只释放匹配的预占；硬盘替换或目标文件出现时保留预占并提示管理员核对。批量清理报告仍待检查的预占数量。创建上传任务时如硬盘换盘、暂存回滚未能确认，或任务与预占关联结果不明，也会保留预占并提示检查；只有确认暂存安全移除、原根未变且预占仍未关联时才释放。Web 与 Flutter 文件上传对无法确认的取消结果给出提示；Flutter 相关代码已做静态检查，Widget 和真实设备验收尚未完成。

## 后端性能

- 图库/影院按最多 200 项批量读取索引并用短事务提交，探测在事务外执行；未变化照片只更新扫描标记，影院复用有效探测结果，保留用户确认的元数据和观看记录。
- 文件排序分页提前排除无法入选的候选项；空缩略图缓存不查询全媒体库；下载进度和活动告警没有变化时不重复写入 SQLite；指标/任务历史按索引边界保留。
- 回收站元数据读取限制为 64 KiB，异常大文件、链接和 FIFO 不会被完整读入内存，原件保留。未更改成员授权、物理根校验或 `enforcement=pending`。
- 上传完成、文件复制/移动、回收站删除/恢复使用服务端按物理根防抖的媒体扫描触发，不再要求成员调用管理员扫描接口；默认根的全局媒体扫描取消/重试映射到 RootRegistry 默认根，主机级任务列表和历史继续保留配置备份等记录，独立根仍由独立任务中心管理。扫描触发合并并非实时增量文件系统事件，目录重度更新及应用重启仍由周期性对账补齐。
- 局部合成对照、复现方式与仍缺的实际负载证据见 [性能文档](PERFORMANCE.md)。不能将分配量下降等同于整进程 RSS 或真实设备验收。

## 重要存储约定

- **每盘独立额度**：每个成员在 A 盘 100 GiB、B 盘 100 GiB 是两份相互独立的额度，A 盘的文件/照片/视频合计只占 A 盘的一份。账本记录的 `accountedBytes` 与 `reservedBytes` 不等同于实际整盘扫描用量；离线代际也不能直接清零。
- **根身份优先**：离线盘不自动转向另一盘，同路径/同名新设备也不自动继承旧权限。管理员放弃已移除旧根的绑定，表示重新建空目录，**不会物理删除或迁移旧数据**。
- **配置快照不是数据备份**：请另行使用 Time Machine 或独立存储备份文件原件，避免将唯一数据留在 Beta。
- **接口单版本**：全局和指定根均为 v2；文档中的历史 v1 记录不得作为当前调用示例。
