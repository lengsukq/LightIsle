# 产品范围：LightIsle

> **Flutter 范围增补（2026-10-22）：** 用户新增要求实现 Android、macOS、iOS Flutter 客户端，工程位于 `apps/flutter`；这更新了本文原先“仅 Mac/Web、不安排原生移动端”的客户端范围。NAS 后端与原生管理端仍为 macOS arm64，生命周期和本机权限边界不变。[实现与验证记录](FLUTTER_CLIENT.md)。

> **最新产品范围（2026-10-23）：** 个人/家庭 NAS，服务端与原生管理端仅 macOS arm64，保留 Web；现有 Flutter Android/iOS/macOS 独立客户端**已有预览代码但可暂缓增强**。最新优先级以 [个人版 fnOS 对标与排期](FNOS_PARITY_PRIORITIES.md) 为准，[个人 NAS 计划](PERSONAL_NAS_PLAN.md) 保留历史分批记录。充分依赖 macOS 原生文件系统、SMB、Time Machine、Spotlight/FSEvents 和 SQLite，不开发企业级备份/跨盘事务平台。

## 面向谁

个人使用的 Apple Silicon Mac、内置及外接存储盘与浏览器。用户需要先启动 LightIsle.app 才能启用 NAS；完全退出 Mac App 就停止它启动的 Go 后端，并断开手机访问。首版面向个人或家庭局域网，异地访问必须通过经过保护的网络通道。

## P0：最小可用 NAS

- **Mac 原生 App 是管理端**：原生管理员初始化、本机系统指标、服务与存储设置；打开 App 自动启动 Go、退出 App 停止 Go。文件/图库/影视和后续管理员用户操作只在独立 Web 用户端呈现。
- **全端视觉一致**：Mac 与 Web 都向 iOS 27 / macOS 27 Liquid Glass 视觉语言靠齐；内容清晰与性能优先，按平台适配导航/返回手势。

| 模块 | 必备能力 | 边界与行为 |
| --- | --- | --- |
| 概览 | CPU / 内存 / 磁盘 / 网络、服务状态 | 只读指标，受采样频率限制 |
| 文件 | 文件列表、目录树、搜索、批量操作、续传上传、Range 下载、预览、回收站 | 仅在管理员授权的根目录内操作；图库/影视不重复保存原始文件 |
| 图库 | 时间线、相册、收藏、EXIF、HEIC、照片视频混排 | 派生自统一文件索引；缩略图是可重建缓存 |
| 影视 | 海报墙、电影/剧集、字幕、进度、播放 | 直放优先；播放不兼容时回退到按需转码 |
| 存储 | 本机/外接磁盘发现、容量、挂载状态、基本健康信息 | 不碰系统盘分区及抹除；硬件信息允许显示“不支持” |
| 账号与任务 | 首任管理员由 Mac App 初始化，后续账号由管理员在 Web 创建；设备会话、任务队列及审计 | Web 不提供首次管理员注册接口；每个文件/设备操作都执行权限校验 |
| 手机 | Android 浏览器能完成主要 NAS 操作 | PWA 先行，原生后台照片备份不在当前范围 |

## P1：增强功能

- macOS SMB/Time Machine 的只读状态检查、配置引导和源数据卷备份覆盖提示；轻量 SQLite 元数据备份与恢复演练。系统账号 ACL 不等于 LightIsle 的用户授权，不自动对外共享整棵数据目录。
- Bonjour、按需 WebDAV、私人组网引导及系统通知；可选 Docker/Colima、Compose 模板。
- 个人会话管理、有限期分享、任务历史与故障事件。

## P2：按需高级能力

- AI 人脸识别、语义照片搜索、重复文件检测、影视元数据增强。
- 必须支持关闭，不得成为核心服务启动依赖。

## 跨功能约定

1. 原始文件始终以 macOS 授权数据盘为事实来源。图库与影视引用统一文件记录，不重复保存原始内容。
2. 移动、重命名、删除后更新索引；未连接的外置卷标记离线，**不能当作文件被删除**。
3. 区分“移出图库/影视库”和“删除原始文件”；后者必须二次确认。
4. 图片/影视自动索引与缩略图可重建；**账号、授权、手动私人相册/收藏与配置等不可再生数据必须有可验证的 SQLite 备份与恢复**。优先检查 Time Machine 是否真实覆盖内置盘和外置数据卷；同盘 APFS 快照不等于独立备份。
5. 已提供的长任务需要有状态、取消、资源边界和可解释的错误；未完操作不得覆盖已有文件或自动永久删源。**不要求为每种文件操作建立企业级持久事务队列或跨磁盘原子移动**。

## 暂不承诺

- 不做其他系统后端（Linux / Windows / Intel macOS）。
- 不做 fnOS 同等级磁盘阵列、跨盘冗余、自动修复的存储池；也不开发企业级联合灾难恢复、复杂跨盘事务、另一套文件版本/增量备份引擎。
- 不承诺任意 HEVC/HDR/音轨在浏览器免转码。
- 不承诺 Mac 完全关机后无需外部设备就能远程启动。

## 用户体验验收原则

- Android 竖屏文件、相册、播放器基本操作无横向溢出或遮挡。
- 盘离线、权限不足、视频无法播放、Docker 未安装时提供可识别的错误状态。
- 上下传和媒体索引必须有任务详情；删除、格式化和关机必须有明确提示。
- 默认不把任何管理端口暴露到公网。
- Mac / Web 的色彩、圆角、图标风格、导航层级和组件状态使用同一语义设计系统；同时支持浅色、深色、减少动态与减少透明度。
- 完全退出 Mac App 后，Go API 必须停止；关闭 App 不应自动关闭用户独立启动的第三方 Docker 容器。
