# LightIsle 产品理念、目标与边界

> **服务于个人与家庭，而不是另一套 NAS 操作系统。** 本文只写长期产品决策；当前能力见 [STATUS](STATUS.md)，未完成项目见 [ROADMAP](ROADMAP.md)，实现与安全约束见 [ARCHITECTURE](ARCHITECTURE.md)、[SECURITY](SECURITY.md)。

## 产品愿景

> **Your Mac. Your NAS.**
>
> **不换系统，也能拥有完整的 NAS 体验。**

LightIsle 的使命是：**让普通用户把现有 Apple Silicon Mac，尤其是常开的 Mac mini，直接变成易用、可靠、私有的个人与家庭 NAS**。不要求刷机、重装或替换 macOS，不强制搬迁原有文件，也不让 NAS 占据这台 Mac 的全部用途。

我们在**用户可感知的 NAS 体验**上对标飞牛 fnOS 等成熟家庭 NAS 产品，包括文件管理、图库、影音、成员管理与多端访问；**不对标其操作系统安装路线**，也不追求完全复制 RAID/ZFS 等底层能力。LightIsle 是运行于 macOS 之上的 NAS 应用平台，不是新的 NAS 操作系统。

### 核心产品理念

1. **安装应用，而不是改造电脑**：用原生 Mac App 完成首次初始化、存储授权和服务管理，尽可能减少额外依赖与运维前置条件。
2. **文件属于用户，不属于应用**：尊重已有磁盘、目录和 Finder 工作流。存储根内的原始文件仍由 macOS 文件系统管理；索引、缩略图和媒体组织信息为可再生的附加能力，不强制导入应用私有仓库。
3. **一机多用**：NAS 服务与用户现有的办公、开发、影音及自动化工作并存。后台运行不能以破坏 macOS 日常体验为代价。
4. **个人家庭优先，完整闭环优先**：简单的成员授权、跨端使用和媒体体验比企业级功能堆叠更重要；每个能力都需覆盖失败反馈、权限与恢复路径。
5. **数据安全高于视觉和功能数量**：磁盘离线不等于数据删除；来源身份不明时安全拒绝写入，危险操作须有明确确认，不把配置备份误称为原始数据备份。
6. **轻量、稳定、可验证**：优先复用 macOS 原生能力，以真实 Mac mini、移动设备和外接盘验收为依据，不把代码存在或自动化测试通过当作全部完成。

## 产品目标与交付原则

以下为**长期产品目标与优先方向，不是当前完成清单**。是否已实现、哪些仍需真机验证，分别以 [STATUS](STATUS.md)、[ROADMAP](ROADMAP.md) 与 [DEVICE_ACCEPTANCE](DEVICE_ACCEPTANCE.md) 为准，避免多处重复维护完成状态。

| 方向 | 目标体验 | 衡量重点 |
| --- | --- | --- |
| **安装与初始化** | 现有 Mac 安装 App 即可创建管理员、配置授权存储根并开始局域网使用，不重装系统 | 首次使用流程清晰；失败可诊断；依赖可选 |
| **原位文件管理** | 文件保留在 Mac 内置或外接盘，Finder 与 LightIsle 操作同一份已授权文件 | 读写、移动、覆盖、删除和权限行为正确；不静默迁移数据 |
| **多盘与成员空间** | 多物理磁盘、个人空间、角色权限及容量管理可理解、可恢复 | 磁盘身份、离线重连、额度核算与访问隔离可靠 |
| **家庭照片与影音** | 对齐成熟相册时间线、媒体浏览和播放交互，支持家庭常用场景 | 照片备份、预览、时间线、视频播放及异常恢复形成闭环 |
| **多端访问** | macOS 管理端、Web/PWA 与移动客户端协同使用同一台 Mac NAS | 状态一致、窄屏与触控适配、连接失败提示清晰 |
| **后台运行与网络** | Mac mini 常驻服务，局域网优先，可自主选择安全远程访问 | 重启、网络变化、任务中断、可选组件缺失时行为可预期 |
| **数据保护与交付** | 保证文件原件安全，清楚界定配置备份与数据备份责任 | 核心路径自动化回归、实盘/真机验收、版本发布门禁 |

### 产品成功的判断方式

- **体验标准**：对标飞牛 fnOS 的是个人家庭日常 NAS 使用体验，而不是磁盘系统功能的全面平替；不以功能列表的数量衡量成败。
- **安装标准**：无需更换 macOS、强制 Docker 化或整体搬迁存量文件，就能完成核心家庭 NAS 路径。
- **安全标准**：文件原件与目录权限的正确性优先于界面完成度；真实磁盘故障、超额写入和恢复过程须留有验收证据。
- **稳定标准**：保留已登记的 Mac mini 连续 7 天用户实机运行反馈，但其他场景和正式发布证据仍须分别验收，不能据此推断全面通过。
- **诚实表达**：产品愿景、代码能力和正式发布状态分别维护，营销文案不把规划功能描述为已经交付。

### 非目标

不开发替代 macOS 的独立操作系统，不承诺与飞牛 fnOS 在 RAID/ZFS、文件系统管理、系统级备份、整机灾备等底层能力等价；具体排除范围见下文「明确不做」。

## 系统与应用各做什么

| macOS / 用户现有工具 | LightIsle |
| --- | --- |
| APFS/POSIX 文件读写、磁盘挂载、本机授权与系统废纸篓 | 按物理根代际校验、成员 ACL、文件/分享 API、上传续传与失败反馈 |
| FSEvents / 可选 Spotlight、ImageIO、AVFoundation / VideoToolbox | 权限隔离的媒体索引、缩略图、照片/影音客户端、任务状态与重试 |
| 系统 SMB、Bonjour、用户自行配置的安全组网 | NAS Web/Flutter 用户端、WebDAV 凭据与按根授权、可选 Tunnel/FRP |
| Time Machine / 外部独立数据备份 | 应用配置与 SQLite 一致性快照、校验、明确确认后离线恢复 |
| 用户已安装的 Docker/Colima / FFmpeg / aria2 | 按需检测与管理，组件不可用时给出明确降级；不强制依赖 |

Go Core 运行在 **Apple Silicon macOS 14+**，由 SwiftUI/AppKit Mac 管理端负责生命周期；**关闭窗口保留菜单栏 NAS，明确退出 App 停止服务**。Web/PWA 与 Flutter Android/iOS/macOS 仅为客户端。没有单独 launchd NAS 守护进程，不要求 Docker 或 AI 模型才能启动。

## 家庭使用约定

1. **磁盘为准**：文件、图库、影视及新建相册的原件和目录留在用户选择的存储根，应用数据损坏时仍可通过 macOS 找到；SQLite 媒体索引和缩略图是派生数据。新建相册使用真实文件夹，加入照片由用户选择复制或移动；有内容的相册不能直接删除。共享相册由创建者选择成员，在被分享者的照片目录中使用受控文件夹软链接，只开放被分享相册，默认只读，创建者可授予写入权限。既有数据库相册保留，不自动转换。离线盘不是“文件已删除”。
2. **用户与权限**：首任管理员只能在 Mac 本机初始化；远程用户端不能执行任意宿主命令。macOS SMB 用户/权限与 LightIsle 用户目录 ACL **不自动互通**。
3. **多硬盘**：每个用户可将 `files / photos / videos` 放在不同物理根；以 `rootID + generation` 确认真实硬盘，不以名字或路径猜测。成员每盘独立默认 **100 GiB**，同盘类别共享，管理员不受应用额度限制。**`enforcement=pending`**：尚未覆盖所有可写渠道，不能宣传为已完成的系统硬配额。参见 [ADR 0003](adr/0003-personal-homes-and-quota.md)。
4. **数据故障处理**：盘离线先重新连接，确认旧根不再使用时由管理员**手动放弃绑定、重建空目录**。不自动迁移数据、不悄悄写入别的硬盘，不在不确定状态下释放配额预占。
5. **失败可理解、失败保源**：上传、索引、下载、转码与备份有可观察状态、重试与错误说明；找不到的个人媒体由对应目录所有者查看和处理，管理员可查看全局问题协助排障。覆盖、永久删除、格式化、危险磁盘操作需确定对象与确认。删除目标是复用 macOS 系统废纸篓，不再维护应用回收站；不以“任务完成”掩盖部分成功或恢复未确认。
6. **轻量与多端**：复用系统能力，按需启动第三方进程；Web/Flutter 兼顾窄屏、大字体、浅深色及减少动态效果。可选 AI、Docker、FFmpeg 均非核心功能前提。

## 备份责任

**应用配置备份不包含原始照片、视频或文档。** LightIsle 只提供手动或每周自动 **SQLite/配置快照，最多保留最近 5 份**；原始数据由用户配置 Time Machine 或另一块独立备份介质。必须确认**外接数据卷实际纳入 Time Machine**，同卷 APFS 快照不等于异盘备份；exFAT/NTFS 不具有 APFS 全部语义。数据库与文件分别恢复时可能处于不同时间点，不能承诺“文件 + SQLite”联合原子灾难恢复。实盘恢复仍需 [设备验收](DEVICE_ACCEPTANCE.md)。

## 明确不做

- 自研 RAID/ZFS/Btrfs、存储池、跨盘块级去重、文件版本系统、自动磁盘迁移、企业级联合恢复/事务引擎、HA、LDAP、多租户计费或自研 P2P 穿透。
- 自动格式化/自动删除原数据，直接将 LAN 明文 HTTP 暴露公网，或远程 Web 执行 Mac 特权命令。
- 强制第三方容器、AI、视频转码作为服务启动条件；目前**不做音乐库**。

未来可按真实家庭需求选择 OCR、改进 Live Photo/RAW、压缩包解压、独立远程备份等；它们不是当前交付承诺，必须先满足数据安全及真实设备验证。
