## 这一批实际开发的内容

### P0：跨卷单文件可恢复安全移动（开发版）

- 原有的 Mac 私有 IPC `export start` 新增 `mode: move`，UI 的文件选择器同时提供“安全复制”和“复制后移入回收站”两种**明确选择**；源文件夹仍仅支持复制。
- `files.Manager.MoveOut` 在私有应用目录记录不可覆盖的随机迁移 ID、源路径、目标路径、阶段与时间，写入时包含临时文件、文件内容 fsync、改名以及父目录 fsync；跨盘数据使用原有逐字节 SHA-256 校验、目标卷原子不覆盖发布、源 inode/大小/修改时间二次核对。
- **目标成功发布、恢复日志成功落盘之后**，源文件才使用已有回收站原子移动；没有永久删除。复制失败、取消、源文件变化或日志损坏会优先**留下源数据**；意外关机可能出现两个副本或“已发布但未移动源”状态，应由 Mac 原生迁移历史核对。
- 在目标发布和日志落盘后、真正移动源文件到回收站前，再次打开原始文件与已发布的目标，独立计算完整 SHA-256、复查文件描述符身份/大小/时间和取消状态；检测到目标被事后篡改或源发生变化将停止后续源处理。新增损坏目标的测试覆盖该保护。
- 本机管理 UI 可查看历史（`export history` 私有命令）；Go 测试覆盖：内容校验后的目标文件、回收站恢复、不覆盖原有目标、路径重叠拒绝、失败记录。普通 Web 用户不能触发跨卷移动。
- **仍非生产完成**：目录树可恢复移动、断点续执行、迁移前容量测算、持久队列优先级、真实第二磁盘的满盘/拔盘/断电试验、外部进程并发变更源文件的强竞争测试。

### P1：按年月组织的照片时间线

- Web 从单一无日期分组的网格调整为年月标题/照片网格交替的真实时间线，照片 tile 位置与月份标题由同一布局引擎计算，采用二分定位虚拟窗口。
- 支持窄屏响应式列数，靠近底部自动分页；有浏览器不支持 IntersectionObserver 或加载失败时仍可手动点击“加载更多”。
- 单元测试覆盖不同月份、未知日期、宽窄视口、10 万条时间数据下的有界 DOM 子集。
- **仍需**：完整年份/月/日期侧栏快速跳转、端到端真机 1 万张 HEIC/JPEG/视频的滚动测试、分页增删一致性和共享/私人相册区分。

### P1：影视手动刮削/元数据匹配

- 服务器新增电影/分集同名 NFO 读取：只从共享根中读取安全文件句柄，限制 XML 大小，拒绝非影片根元素、损坏或异常字段；电影目录 `movie.nfo` 也可使用。
- 新增 TMDB **按需**搜索和**手动确认匹配**：不会自动遍历媒体库向第三方上传文件名；用户每次提供自己的 TMDB API Read Access Token，密钥只放在 HTTPS 请求体中，不持久化，搜索词由管理员手动确认。
- TMDB 官方 API 域名固定、9 秒超时、响应不超过 1 MiB、最多 10 条结果、严格海报 HTTPS 路径校验，不依赖第三方代理或 Docker。匹配后来源、简介、评分和海报保存到 SQLite；管理员已经手动修改的显示名始终优先，视频原文件和账号观看进度不动。
- Web 影视详情支持 NFO 导入、TMDB 查询/候选预览/确认匹配、原始来源标注及 TMDB 使用声明。
- **仍需**：TMDB API 凭据和网络的真实接入测试、可选受控批量识别与人工复核、影视详情/演员剧集分季、海报代理缓存和隐私、TMDB 官方品牌/logo及商业授权核查、离线 NFO 导出、MOV/MKV/HEVC/HLS 转码矩阵。

### P1：多用户的私人收藏（不破坏既有共享收藏）

- Gallery SQLite 新建以 `user_id + asset_id` 为键的 `personal_favorites`，与原有全家共享的 `assets.favorite` 完全分离，原先共享收藏不会被迁移、覆盖或悄悄变成私人数据。
- Web 新增“我的收藏”过滤和星形个人收藏按钮；有**读取权限**的普通成员可以收藏自己有权查看的照片，不需要目录写入授权，也不会改变其他人的收藏状态。
- 列表在 SQL 分页之前过滤个人收藏且先应用用户授权目录；单个媒体操作再次校验真实文件路径。数据表对被索引删除的照片启用级联清理。
- Go 测试覆盖用户之间不泄漏、只读账号能收藏被授权的文件、对非授权目录禁止操作、原共享收藏保持不变。
- **仍需**：现有共享相册的显式迁移/归属模型、个人收藏 UI 在真实浏览器的端到端验收。独立私人相册已由下节单独实现。

### P1：每个账号独立的私人相册（本轮新增）

- `private_albums` 和 `private_album_items` 与原有全家共享 `albums/album_items` **完全独立**；旧共享相册继续由管理员管理，不做隐式迁移。独立的唯一约束 `(share,user_id,name)`，每账号每卷最多 100 个私人相册。
- 已打通 Web 创建、改名、删除、加入/移出照片、按私人相册过滤；只读成员能组织自己获准查看的照片，不能给不在授权目录中的照片建立有效成员关系。
- 分页前在 SQL 中校验相册归属和当前共享根、用户可访问路径。原始文件、共享收藏、其他账号私人相册不会因相册 CRUD 被修改。
- 测试覆盖已授权/未授权成员、管理员与其他成员不能读写彼此的私人相册、不同授权目录的可见计数、原件保留及 SQLite 关联级联清理。
- **仍需**：真实多设备浏览器 E2E 和账号删除后的跨独立 SQLite 数据清理政策。

### P1：持久安全审计（本轮新增）

- 独立 `accounts.sqlite.audit_events` 记录用户编号、动作分类、路由模板、操作结果和时间。不会保存密码、登录会话密钥、文件正文或临时分享 token；公开分享下载以固定类别记录，避免持久保存能力型链接。
- 只对实际的账号与授权、文件、上传、图库/影视、分享、通知确认等写入操作记录；管理员有 Web 分页查询 UI。历史上限 20,000 条、90 天自动淘汰。
- 单元/HTTP 测试验证普通成员无法读取审计、分页正常、异常输入不能注入敏感 URL 或换行。
- **仍需**：更完整的权限拒绝记录、导出与防篡改校验及真正长期故障注入；当前写审计失败会记录后端告警而不会回滚已执行的用户文件操作。

### P1：应用内异常通知（本轮新增）

- 每分钟被动检查共享卷在线状态、可用容量，以及持久任务日志中的备份、图库、影视扫描失败。低空间阈值为 2 GiB 或可用容量不足 5%。
- `tasks.sqlite.system_alerts` 持久记录故障、首次发生时间、严重程度、确认与恢复状态。状态未变化时去重；恢复后若同类故障再发生，重新变为待确认。
- 管理员可在 Web 设置中查看当前/历史通知和确认已知晓。确认不会消除真实故障、不会自动清理数据或执行危险恢复。
- **仍需**：macOS UserNotifications 授权与原生桌面推送、可配置阈值、不同类型存储与备份设备的大规模实机验收。

## 不纳入 P0/P1 的 Docker 约束

Docker 不内置任何引擎、镜像、Compose 应用、Docker Desktop 安装器或 Colima 虚拟机；只连接用户自行安装的 Docker CLI / 本机引擎并提供管理能力。镜像加速源只是**可选配置预设**，不自动写入或启动 Docker。

## 真实验收标准

- 当前 Go 的单元测试、Race、Web 编译/单元测试和 Swift Release 编译可验证实现没有明显回归，**不能代表物理断电及生产发布通过**。
- 本轮原件不允许被后台任务隐式永久清理；用户的真实数据不可作为自动化测试素材。
- 只有在 `scripts/verify-release-qa.py` 的真实 QA 项目通过、Apple 官方公证成功、双物理盘验证并保留证据之后，才能修改 `docs/PRODUCTION_RELEASE.md` 中的正式发布结论。
